PYTHON · hello.py
from hamingjur import Terminal

term = Terminal()
with term.fullscreen(), term.cbreak(), term.hidden_cursor():
    print(term.home + term.clear, end="")
    print(term.bold_green("Hello from Hamingjur."))

04 / WORKING EXAMPLES

From a request to a result.

Each example makes support and ownership explicit. Use the reference below for every argument, return type, and source docstring.

01 — Discover and read tablet events

Aggregate discovery identifies understood selectors. Query the channel for device-related capabilities, then use the reporting mode that the terminal actually grants.

PYTHON · tablet input
from hamingjur import Terminal
from hamingjur.silkie import TabletMode

term = Terminal()
with term.cbreak():
    caps = term.silkie.capabilities(timeout=0.5)
    if caps and caps.supports("tablet-pointer"):
        mode = TabletMode.TOOLS | TabletMode.TOUCH
        with term.tablet.enabled(mode) as granted:
            while granted:
                key = term.inkey(timeout=0.1)
                if key == "q":
                    break
                if key.tablet is not None:
                    event = key.tablet
                    print(event.position, event.pressure, event.tilt)
    else:
        print("Tablet reporting: not supported")

Touchpad coordinates are available through touchpad_position; they are normalized values, rather than physical screen pixels. Reporting contexts restore the previous mode on exit.

02 — Draw an image and release it

The adaptive image API fits your source and negotiates formats and transfer media. Kitty and Silkie acknowledge the upload. Keep the source image if you plan to redraw after a resize.

PYTHON · uses a local photo.png
from PIL import Image
from hamingjur import Terminal

term = Terminal()
result = None
with Image.open("photo.png") as source, term.cbreak():
    try:
        result = term.graphics.draw(
            source, x=0, y=0, columns=40, rows=12
        )
        term.inkey()
    finally:
        if result and result.acknowledged:
            term.graphics.send(
                term.graphics.delete(result.image_id)
            )
        elif result:
            term.graphics.forget(result.image_id)

Use pixel width/height or cell columns/rows, never both. Source formats include packed grayscale, RGB565, RGB/RGBA, PNG, and HDR half-float RGBA where supported. GPU surfaces require an application-owned descriptor.

03 — Send a retained vector scene

Silkie renders this path scene directly. Kitty and sixel receive a rasterized copy. Shaped text, gradients and pressure strokes require native Silkie.

PYTHON · Silkie vector images
from hamingjur import Terminal, graphics

term = Terminal()
with term.cbreak():
    if term.graphics.supports(200):
        records = [
            graphics.vector_record(
                "p", id=1, d="M0,0H240V100H0Z", fill="#183e35"
            ),
            graphics.vector_record(
                "p", id=2, d="M24,76L76,24L128,76Z", fill="#c4e6a8"
            ),
        ]
        try:
            term.graphics.send(graphics.scene(
                records, image_id=7, width=240, height=100, q=1
            ))
            term.inkey()
        finally:
            if term.does_kitty_graphics():
                term.graphics.send(graphics.delete(7, q=2))
            else:
                term.graphics.forget(7)
    else:
        print("Vector graphics: not supported")

04 — Keep input and application state separate

LineEditor handles editing, history, suggestions, grapheme movement, and optional password masking. Your application decides where and when to render.

PYTHON · a headless editor in an event loop
from hamingjur import Terminal, LineEditor, LineHistory

term = Terminal()
editor = LineEditor(history=LineHistory(), max_width=term.width)
with term.cbreak():
    while True:
        print(editor.render(term, row=0, width=term.width),
              end="", flush=True)
        result = editor.feed_key(term.inkey())
        if result.line is not None:
            break
        if result.interrupt or result.eof:
            break

Feed bracketed-paste contents through insert_text(). For asynchronous applications, use await term.async_inkey() in your own async event loop.

05 / API CONTRACTS

Read the reply you received.

Query APIs return different objects. This distinction matters when decoding responses or handling unsupported features.

Terminal.query(sequence, response, timeout)str | None

The full matched response string, or None. It is not a regular-expression match object. Parse the returned string with the appropriate decoder.

Channel.query(timeout)ProtocolEvent | None

A structured Silkie capability report. Inspect fields, integer(), or number(). A selector’s support does not imply attached hardware.

Graphics.query(data, ...)ProtocolEvent | None

A graphics reply. A successful probe has event.payload == "OK". supports() turns a format probe into a boolean.

Terminal.inkey() / async_inkey()Keystroke

A string-compatible key with name and structured protocol_event or tablet properties. Empty input can indicate a timeout.

Graphics.draw(source, ...)DrawnImage | None

An acknowledged image placement; disabled styling returns None. Upload errors raise, and missing acknowledgements raise TimeoutError.

RemoteControl.call(name, payload, ...)decoded response data

Returns the terminal’s JSON data. Refusal raises RemoteControlError; a missing complete reply raises TimeoutError. Terminal permission is required.

  • Restore modes. enabled() reads the existing mode, checks granted bits, and restores the previous value in finally. Leave contexts before suspending and re-enter after resuming.
  • Own resource lifetimes. Release images and uploaded font handles. GPU surface allocation stays with your application. File, shared-memory, and direct transports have different lifecycles.
  • Serialize shared terminal I/O. Complete a chunked transmission before starting another command on that protocol. Queries preserve unrelated keyboard input.
  • Interpret payloads by protocol. event.data decodes base64 only where the protocol defines it. Graphics errors and notification activations may carry plain text.
  • Preserve complete data. Image transmissions, event reports, and retained editing state do not have arbitrary total-size caps. Actual wire ranges and packet sizes still apply; allocation failures propagate.

An abstraction for color, style, positioning, and input in the terminal.

This keeps the endless calls to ``tigetstr()`` and ``tparm()`` out of your code, acts
intelligently when somebody pipes your output to a non-terminal, and abstracts over the
complexity of unbuffered keyboard input. It uses the terminfo database to remain portable across
terminal types.

Constructor
-----------
Initialize the terminal.

:arg str kind: A terminal string used for capability database, defaults to the value of the
    ``TERM`` environment variable when undefined. If the terminal supports XTGETTCAP
    extension, the 'TN' capability name reported has precedence over 'kind'.

:arg file stream: A file-like object representing the Terminal output.
    Defaults to the original value of :obj:`sys.__stdout__`, like
    :func:`curses.initscr` does.

    If ``stream`` is not a tty, empty Unicode strings are returned for
    all capability values, so things like piping your program output to
    a pipe or file does not emit terminal sequences.

:arg bool force_styling: Whether to force the emission of capabilities
    even if :obj:`sys.__stdout__` does not seem to be connected to a
    terminal. If you want to force styling to not happen, use
    ``force_styling=None``.

    This comes in handy if users are trying to pipe your output through
    something like ``less -r`` or build systems which support decoding
    of terminal sequences.

    When the OS Environment variable FORCE_COLOR_ or CLICOLOR_FORCE_ is
    *non-empty*, styling is used no matter the value specified by
    ``force_styling``.

    Conversely, When OS Environment variable NO_COLOR_ is *non-empty*,
    styling is **not** used no matter the value specified by
    ``force_styling``, FORCE_COLOR_, or CLICOLOR_FORCE_.

    .. _CLICOLOR_FORCE: https://bixense.com/clicolors/

hamingjur.terminal.Terminal.location(x: Optional[int]=None, y: Optional[int]=None) -> Generator[None, None, None]
Context manager for temporarily moving the cursor.

:arg int x: horizontal position, from left, *0*, to right edge of screen, *self.width - 1*.
:arg int y: vertical position, from top, *0*, to bottom of screen, *self.height - 1*.
:return: a context manager.

Move the cursor to a certain position on entry, do any kind of I/O, and upon exit
let you print stuff there, then return the cursor to its original position:


.. code-block:: python

    term = Terminal()
    with term.location(y=0, x=0):
        for row_num in range(term.height-1):
            print('Row #{row_num}')
    print(term.clear_eol + 'Back to original location.')

Specify ``x`` to move to a certain column, ``y`` to move to a certain
row, both, or neither. If you specify neither, only the saving and
restoration of cursor position will happen. This can be useful if you
simply want to restore your place after doing some manual cursor
movement.

Calls cannot be nested: only one should be entered at a time.

.. note:: The argument order *(x, y)* differs from the return value order *(y, x)*
    of :meth:`get_location`, or argument order *(y, x)* of :meth:`move`. This is
    for API Compatibility with the blessings library, sorry for the trouble!

Permalink Source ↗
hamingjur.terminal.Terminal.get_location(timeout: Optional[float]=TERMINAL_QUERY_TIMEOUT_SECONDS) -> Tuple[int, int]
Return tuple (row, column) of cursor position.

When :attr:`is_a_tty` is False, no sequences are transmitted or response
awaited, and the value ``(-1, -1)`` is returned without inquiry.

:arg float timeout: Return after time elapsed in seconds with value ``(-1, -1)`` indicating
    that the remote end did not respond.
:rtype: tuple
:returns: cursor position as tuple in form of ``(y, x)``.  Always ensure the return value is
    checked for ``(-1, -1)``.

The location of the cursor is determined by emitting the ``u7`` terminal capability for the
VT100 `Query Cursor Position
<https://www2.ccs.neu.edu/research/gpc/VonaUtils/vona/terminal/vtansi.htm#status>`_.
This elicits a response from a reply string described by capability ``u6`` for the VT100
response.

The ``(y, x)`` return value matches the parameter order of the :meth:`move_yx` capability.
The following sequence should cause the cursor to not move at all::

    >>> term = Terminal()
    >>> term.move_yx(*term.get_location())

And the following should assert True with a terminal:

    >>> term = Terminal()
    >>> given_y, given_x = 10, 20
    >>> with term.location(y=given_y, x=given_x):
    ...     result_y, result_x = term.get_location()
    ...
    >>> assert given_x == result_x, (given_x, result_x)
    >>> assert given_y == result_y, (given_y, result_y)

suffix.  See :attr:`key_name` for the same name without the suffix.

hamingjur.colorspace.xparse_color(hex_component: str, bits: int=16) -> int
Scale a hex color component to 16-bit or 8-bit per XParseColor specification.

XParseColor is the X11 color parsing standard used by terminals when responding
to OSC 10/11 color queries. Each color component in the ``rgb:R/G/B`` response
can be 1-4 hex digits, representing 4-bit to 16-bit precision.

XParseColor uses **scaling** (bit replication) to expand shorter values to
16-bit. This differs from HTML/CSS shorthand which uses digit doubling:

- XParseColor ``rgb:`` format (scaling): ``f`` -> ``ffff``, ``0f`` -> ``0f0f``
- HTML/CSS shorthand (doubling): ``#f`` -> ``#ff``, ``#0f`` -> ``#0f``

Scaling examples:

- 1 hex digit (4-bit): ``f`` -> ``ffff`` (15 -> 65535)
- 2 hex digits (8-bit): ``e5`` -> ``e5e5`` (229 -> 58853)
- 3 hex digits (12-bit): ``abc`` -> ``abca`` (2748 -> 43978)
- 4 hex digits (16-bit): ``e5e5`` -> ``e5e5`` (unchanged)

:arg str hex_component: A single hex color component (1-4 hex digits).
:arg int bits: Output precision: 16 (default, 0-65535) or 8 (0-255).
:returns: Scaled integer value at the requested bit depth.
:raises ValueError: If hex_component length is not 1-4 or bits is invalid.
